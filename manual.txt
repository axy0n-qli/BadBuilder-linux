Script created in BadBuilder.sh. To use on Linux:


chmod +x BadBuilder.sh
sudo ./BadBuilder.sh

Required dependencies (one-line install):

Debian/Ubuntu:
sudo apt install util-linux dosfstools parted curl jq unzip p7zip-full unrar

Fedora/RHEL:
sudo dnf install util-linux dosfstools parted curl jq unzip p7zip p7zip-plugins unar

Arch/Omarchy:
sudo pacman -S util-linux dosfstools parted curl jq unzip p7zip unrar

What the script implements (same scope as the C# version):

Feature	Implementation
ANSI color TUI		ASCII art + numbered menus
Disk enumeration		lsblk -J → shows /dev/sdX, size, type
FAT32 formatting		parted (MBR table) + mkfs.fat -F 32 -n BADUPDATE
GitHub download		curl + jq for the GitHub API with per-version cache
SHA-256 verification		sha256sum compared with the release hash
File extraction		unzip / 7z / unrar/unar depending on extension
Exploits			BadUpdate, ABadAvatar, ABadAvatarUpdate
Bootstraps			XeUnshackle (with <SUBFOLDER> resolve) + FreeMyXe
Built-in homebrew		Aurora, XeXMenu, Simple 360 NAND Flasher
Custom homebrew			Adds a local file, detects entry point manually
Auto-launch			Edits launch.ini with sed (XeUnshackle only)
Dashboard update		Direct download from the Microsoft server
